📸 이미지 넣기 (파일 이름)

파일 이름이 메뉴 이름과 같으면 자동으로 연결돼요. (예: 가츠동.png → 가츠동)
이미지 파일을 화면에 끌어다 놓아도 됩니다.

✂️ Gemini 시트 자르기

4×4 시트를 칸별로 잘라 메뉴에 연결해요. 파일 이름에 묶음3처럼 번호가 있으면 자동으로 묶음을 맞춰요.
'묶음'이 들어간 파일은 끌어다 놓아도 시트로 인식해요.

🗂️ 선택지별 메뉴

왼쪽에서 선택지를 누르면 들어 있는 메뉴가 보여요. 메뉴를 누르면 이름·이미지·선택지를 한 번에 고칠 수 있어요.

💾 백업 · 배포 · 초기화

🔗 링크 미리보기 이미지

카톡·디스코드에 링크를 붙이면 뜨는 이미지예요. 넣어둔 음식 이미지 3개로 자동으로 만들어져요.
미리보기가 뜨려면 사이트 주소를 꼭 넣어주세요.
